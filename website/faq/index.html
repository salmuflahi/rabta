Questions worth asking first

Most of these are about what Rabta can reach and what it does with it. Every answer here is checked against the source before it ships; where a thing is not built yet, this page says so rather than implying it is.

Applies to Rabta 0.1.0

What it does

What exactly is a capsule?

The arrangement around one task, written down: which files are open and in what order, the terminal working directories, the Git branch, and the browser tab URLs. Save it, switch away, resume it later.

Does it save my work for me?

No. Rabta records where things were, not what was in them. Your editor still saves your files; Git still holds your history. If Rabta vanished, nothing you wrote would go with it.

What happens if a tool isn't running when I resume?

The restore reports it per tool — restored, queued for the next time that tool reconnects, or skipped with a reason. It does not claim a success it did not get.

Privacy and access

Is there an account?

No, and there is no server to have one on. The hub binds to 127.0.0.1 and nothing else.

Can it read my files?

It stores paths. Not file contents, not diffs, not terminal output.

Can the browser extension read the pages I'm on?

No. It requests no host permissions and runs no content scripts — its manifest declares only tabs, storage and alarms. It reads tab URLs and titles, and cannot read page contents, form data or cookies. Incognito tabs and anything that isn't http(s) are excluded.

Does it phone home?

No. v0.1.0 makes no outbound request on launch or on a timer. There is no analytics SDK and no crash reporter. The one network call in the app is a Git fetch, and only when you click it.

Does it store my GitHub token?

No. The optional GitHub features shell out to your own authenticated gh CLI. Rabta never sees a credential.

Git and your working tree

Will resuming a capsule change my branch?

Only if the switch is safe. A working tree that the switch would disturb refuses it, with a message saying why. Nothing is reset, stashed or discarded on your behalf.

Does it close things I'm using?

Not by default — resuming only opens. Focus mode, which is opt-in, will put away what isn't part of the task, and even then it stops at unsaved files, running terminals and anything you've pinned.

Running it

What do I need?

macOS 11 or later on Apple silicon. An Intel or universal build is not available yet — see the roadmap.

Does it update itself?

No. Auto-update is not wired in 0.1.0, so new versions are a manual download. That also means nothing checks a server on your behalf.

What does it cost?

Nothing. It is free and MIT-licensed, and the whole thing is on GitHub if you would rather read it than trust it.

Which editors work?

VS Code and Cursor through the editor extension, and Chrome through the browser extension. Setting both up is covered in the setup guide.
