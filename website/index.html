Capsule

Four steps, then it's a habit.

You work in tasks. Rabta watches the tools you connected and remembers what each task was using.

  1. Step 1

    Connect your tools

    Install the editor connector. It finds the app on your machine and pairs itself — no sign-in.

  2. Step 2

    Register a project

    Point Rabta at a repo. It reads the path and branch, and leaves your files alone.

  3. Step 3

    Work in tasks

    Give the thing you're doing a name. Save its state when you step away — or just switch, which saves it for you.

  4. Step 4

    Resume

    Pick the task back up. Your files, terminals, tabs and branch come back, and Rabta tells you what it restored.

Built in

Small tool. Specific job.

Rabta is not a task manager, a note app or a time tracker. It restores working context, and it tries to do that one thing properly.

  • Editor files and terminals

    The files you had open, the workspace folder, and the terminals you were using — reopened together.

  • Browser tabs

    The tabs that belonged to the task, by URL and title. Page contents are never read.

  • Git branch, safely

    Restores put you back on the task's branch — and stop rather than force a checkout over your changes.

  • Approval before access

    A connector can't talk to the hub until you approve it in the app, and it can only use the capabilities it declared.

  • Your data, on your disk

    Capsules are rows in a local database you can open in Finder. Uninstalling takes them with it.

  • An honest activity log

    Every command sent and every reply received, so a restore that didn't work is something you can actually diagnose.

When

The moments this pays for itself.

  • A prod bug lands You drop everything mid-feature

    Save the feature task as it stands, fix the bug on its own branch, then resume — instead of trying to remember which six files you had open.
  • Monday morning Friday's context is gone

    Open the task you were on and get the same files, terminals, tabs and branch back, without reconstructing them from your commit log.
  • Two repos, one afternoon Switching projects, not just branches

    Each project keeps its own tasks. Moving between them swaps the whole workspace, not just the working directory.
  • A review request A ten-minute interruption that costs an hour

    The cost of an interruption is mostly the rebuild afterwards. Save before you go, resume when you're back.
  • Research-heavy work The tabs are the work

    Twelve reference tabs are part of the task. They come back with it instead of being closed and hunted down again.
Local-first

There is no Rabta server.

Not "we don't look at your data" — there is nowhere for it to go. The app and its connectors run on your machine and talk to each other over a loopback port that is never exposed to your network.

  • No account

    Nothing to sign into

    No login, no email, no profile. Open the app and use it.

  • No cloud

    No sync, no backend

    Capsules are rows in a database file on your disk. Nothing is uploaded.

  • No telemetry

    Nothing is measured

    No analytics, no usage pings, no crash reporting service, no ads.

  • Pointers only

    Your code is not copied

    Rabta stores file paths, branch names and tab URLs — never file contents, terminal output or page data.

  • Localhost

    Bound to 127.0.0.1

    The hub isn't exposed to your network, and connectors authenticate against a secret written locally per run.

  • This site

    No third-party requests

    This page loads no analytics, no hosted fonts and no tracking scripts. Only links you click go anywhere else.

The full privacy policy spells out exactly what is stored, where, and what the connectors can reach.

Install

Running in about two minutes.

The app is signed with an Apple Developer ID and notarized, so it opens with a normal double-click — no right-click trick, no Gatekeeper warning.

  1. 1

    Install the app

    Open Rabta_0.1.0_aarch64.dmg and drag Rabta into Applications. Launch it — the local hub starts with the window.

  2. 2

    Add the editor connector

    In Cursor, VSCodium or Windsurf, search the Extensions panel for Rabta Connector. In VS Code, install the signed .vsix — see the setup guide. It pairs itself; there's nothing to sign into.

  3. 3

    Register a project

    Point Rabta at a git repository. It reads the path and default branch and doesn't touch anything else.

  4. 4

    Save your first capsule

    Name the task you're on, then press Save State. Switch away and resume it to see the workspace come back.

Connectors

The app captures. Connectors reach.

The desktop app can't see inside your editor or browser on its own. Each connector is a small bridge that talks only to the hub on your machine.

  • Editor

    Available now

    Snapshots and reopens your open files, workspace folder and terminals. Published on Open VSX, which Cursor, VSCodium and Windsurf install from directly — search "Rabta Connector" in the Extensions panel. For stock VS Code, install the signed .vsix; it is not on the Microsoft Marketplace yet.

    rabta-connect.rabta-vscode · 0.1.0
    Get it on Open VSX

  • Browser

    Pending review

    Captures the tab URLs and titles belonging to a task and reopens them on restore. It requests no host permissions and runs no content scripts, so it is structurally unable to read page contents — and it pairs only after you approve it in the app.

    Chrome Web Store · in review
    Not installable yet

Rabta works without the browser connector — you just get editor, terminal and git state until it lands.
