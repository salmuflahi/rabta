capture

Save the task
you’re leaving.

Rabta records what a task had open — the files and cursor position, the terminal sessions, the browser tabs, the git branch — and keeps it as a capsule.

It stores pointers, not contents: paths and names, never your code.

What happens between leaving and returning

between

capture Rabta writes down what the task had open.
leave Something else needs doing. The windows close.
return You come back to the task, days later.
restore The workspace is put back around it.

restore

Pick it up exactly
where it was.

Choose a task and Rabta puts the workspace back around it. Git goes first, because switching a branch changes files on disk.

Some things return immediately. Some, like browser tabs, come back on the next reload — and it tells you which is which.

connectors

Your tools reconnect
to the task.

Rabta talks to your editor and browser through small connectors that run locally, over 127.0.0.1 and nothing else.

Your editor pairs itself by reading a file only your account can read. Chrome cannot, so it asks. Between them they are allowed to do exactly five things.

macOS appThe signed, notarized .dmg — 5.5 MB, Apple Silicon Available
Editor connectorOn Open VSX — Cursor, VSCodium and Windsurf install it directly. Stock VS Code installs the same .vsix by hand. Published
Browser connectorSubmitted to the Chrome Web Store. Rabta works without it — you get editor, terminal and git state until it lands. In review

workspace.open · workspace.snapshot · terminal.list · tabs.list · tabs.open

The Chrome connector reads tab URLs and titles only. It requests no host permissions and runs no content scripts, so it is structurally unable to read page contents.

privacy

It never leaves
your Mac.

There is no Rabta account and no Rabta server. Your capsules live in one folder on your own disk.

Your project code is never uploaded — Rabta stores the path to a file, not the file.

  • no account
  • no telemetry
  • no analytics
  • no crash reporting
  • no update checks
  • no cloud

The one thing that can reach the network is the optional GitHub feature, and it runs the gh tool you installed yourself.

Connectors talk only to 127.0.0.1. Nothing is exposed to the network.

Rabta 0.1.0 has no auto-updater and makes no outbound request on launch or on a timer.
