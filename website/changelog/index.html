0.1.0 — 29 July 2026

First public release · Apple silicon · macOS 11+

The first version anyone else can run. Capsules save the arrangement around a task — open files and their order, terminal working directories, the Git branch, browser tab URLs — and put it back when you return.

What's in it

A six-section console: Overview, Capsules, Projects, Connectors, Activity and Settings, with a ⌘K command palette. Editor support for VS Code and Cursor, and a Chrome connector for tabs. Restores report per tool, so a partial result reads as partial rather than as success.

What it asks of you

The build is unsigned, so the first launch is right-click → Open rather than a double-click. The extensions install by hand — the setup guide covers both. There is no auto-update, so future versions are a manual download.

What it does not do

No account, no server, no telemetry. The hub binds 127.0.0.1. Details on the Why page.

Before 0.1.0
