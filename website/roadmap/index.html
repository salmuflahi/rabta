What isn't built yet

This page carries no dates. Rabta is one person's work, and a date on unstarted work is a promise made with someone else's time. What follows is ordered by intent, not by schedule.

Next

Known gaps with a clear shape, in rough order.

A restore report

A restore already knows what applied, what is queued and what was skipped, and it says so per tool while it runs. What it does not yet do is hand you that as a report you can read afterwards. This is the largest gap in the product today.

Intel and universal builds

The current bundle is Apple silicon only. Nothing in the app is deliberately arm64-specific; this is packaging work.

Store distribution

The editor extension is on Open VSX and the browser extension is on the Chrome Web Store, which covers Cursor, VSCodium, Windsurf and Chrome. Microsoft's VS Code Marketplace is the gap: stock VS Code does not read Open VSX, so that one install is still a .vsix by hand.

Bulk actions on capsules

Multi-select, so archiving or deleting several is one gesture.

Under consideration

Auto-update

Not wired, and not free: it needs an update endpoint and a signing keypair, and it means the app would start making a network request it does not make today. That tradeoff is the reason this is here rather than under Next.

More connectors

Terminal emulators beyond the built-in support, and other tools that hold part of a task's surface. Each one is a permissions question before it is an engineering one.

Other platforms

macOS is the only tested target. The discovery file and the keychain-adjacent parts would need porting; the rest is not deeply macOS-specific.

Deliberately deferred

Reasonable ideas, consciously not being worked on: a plugin SDK, automation rules, and integrations with issue trackers and design tools. Each would widen what Rabta reaches, and the product is more valuable narrow and trustworthy than broad and vague.

Not planned

Cloud sync, team collaboration, and accounts. These are not scheduling decisions — they are the shape of the product. Rabta has no server, and the guarantees on the Why page hold because of that, not in spite of it. Adding any of the three would mean giving those up.

Want something on this list? Open an issue — that is where this page gets its arguments from.
