# Rabta — website

Public product & download site for **Rabta**, a local-first macOS developer tool
that captures a task's whole workspace — editor files, terminals, browser tabs,
and git branch — into a *capsule*, and restores it on demand.

- **Website:** https://salmuflahi.github.io/rabta/
- **Download (macOS, Apple Silicon):** see the latest [Release](https://github.com/salmuflahi/rabta/releases/latest)
- **Editor connector (Open VSX):** https://open-vsx.org/extension/rabta-connect/rabta-vscode
- **Privacy policy:** https://rabta-privacy.n0bodyy.chatgpt.site/

This repository contains only the marketing website and the release binary.
The Rabta application source is **not** public.
