# OmniBus

OmniBus is a local developer tools hub designed to streamline common workflows and integrate tools seamlessly into a unified interface. It provides a modern, web-based console for managing development tasks, running checks, and accessing integrated services. See the [vision](./docs/vision.md) and [architecture spec](./docs/superpowers/specs/2026-07-17-omnibus-architecture-foundation-design.md) for design details. To get started: run `pnpm install && pnpm test && cargo test` to verify everything works, then `pnpm --filter desktop tauri dev` to launch the OmniBus dev console.
