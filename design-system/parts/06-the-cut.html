The Cut

The one hover in the system. A skewed block waits off the leading edge and lands — the fold's 45° turned into a gesture. Hover or tab into anything below.

A link takes the same gesture

−18°, not 45°. --cut-skew is shallower than the fold because a button is wider than it is tall; −18° is what reads as 45° across a 50px control.

It answers the cursor. --cut-x is set to the edge the pointer actually crossed, so the fill arrives from the side you came from rather than always from the left. It is a whole offset and not a sign multiplier, because calc() will not re-resolve a percentage scaled by a substituted number — written the obvious way it parses cleanly and silently never moves. The default is the left, which is where keyboard focus and a scriptless page enter.

On links it replaces the underline rather than joining it. The resting underline fades out as the fill arrives; drawn as an addition you get two underlines stacked.

Every hover rule has a :focus-visible twin. A test walks the stylesheets and fails on any :hover selector without one, so a keyboard can never get less than a mouse.
