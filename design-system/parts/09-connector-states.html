Connector states

What the browser extension says, and when. Each state names what is true, then what to do about it — and the dot never carries a fact the words do not.

Connected

Tabs are saved with the task you have open in Rabta.

Pairing…

Approve this browser in Rabta if it asks.

Not paired yet

Open Rabta to pair this browser. It only has to happen once.

Rabta isn’t running

Open Rabta and this reconnects on its own.

A token on disk is not a connection. The first version of this popup read the stored pairing token and called that “paired” — so it said paired with the hub closed, which is exactly the situation someone is in when they open it to find out what is wrong. The live socket outranks every other signal.

It re-reads while you watch. Opening the popup is usually what wakes the worker, so a single reading lands mid-dial: a browser three seconds into pairing reported “Not paired yet” and held it until closed and reopened. One dropped reply is not an outage, though — only a popup that has never had an answer treats silence as one.
