# Rabta 0.2.0-beta.1

The expanded Mac app, now available as a downloadable public beta. This release
contains the implemented Rabta redesign, desktop toolbox and self-hosted Teams
preview. It does not claim completion of the full 57-feature Vorssaint scope.

## Download and install

Download `Rabta_0.2.0-beta.1_aarch64.dmg` for an Apple Silicon Mac. Open the disk
image and drag **Rabta Beta** into Applications. A ZIP is also provided.

This beta is **ad hoc signed and not notarized by Apple**. macOS may require
approval in System Settings → Privacy & Security after your first launch attempt.
The existing signed 0.1.0 remains the latest stable release; GitHub lists this
new version as a prerelease.

Rabta Beta uses a separate `com.omnibus.dev.beta` data directory and starts with
an empty workspace. It does not import or overwrite stable Rabta or Rabta Preview
data. Quit those apps before opening Beta, then pair your connectors in Beta.
Delete only the Beta application to stop testing; existing stable data remains.

## Included

- The Lens design and one app shell for workspace capture, restore and tools.
- 28 desktop tools, searchable across Everyday, Developer, Creator and Student
  modes. These modes prioritize tools without putting them behind a paywall.
- Image conversion, resize, crop, compression, rotate/flip, palette extraction,
  manual/color-based background editing, SVG-to-code and local video/audio
  trimming and conversion. Image enlargement is resizing, not AI upscaling.
- Text comparison, timestamps, study cards and quizzes from entered notes, and
  content planning with calendar reminders. Reminders do not publish posts.
- Opt-in, memory-only text clipboard history; window inventory and layouts;
  screen OCR/barcodes; audio output switching; system metrics; native exports.
- Teams private work areas, explicitly published live text previews, presence,
  selected file sharing, and proposals that recipients review before applying.
- Eight bounded utility tools in the MCP source for connected AI assistants.

## Teams and AI setup

Teams requires the self-hosted service in `services/teams`; see
[`docs/teams-service.md`](https://github.com/salmuflahi/rabta/blob/v0.2.0-beta.1/docs/teams-service.md). Remote teammates need a reachable
HTTPS endpoint. There is no managed Rabta Teams server in this beta, and it does
not stream arbitrary Mac application windows.

For MCP access to the Beta workspace, build `packages/mcp` from this release and
set `RABTA_DB` to `~/Library/Application Support/com.omnibus.dev.beta/omnibus.db`
(use the expanded absolute path in the client's configuration). Capture/restore
still requires opt-in Agent access in Beta. This release does not publish a new
npm package or provide a hosted AI model.

## Verification and remaining work

The release workflow gates publication on desktop, MCP, Teams, window and Rust
tests; frontend and native compilation; packaged version and identity checks;
signature and DMG verification; and recorded SHA-256 asset checksums. `BUILD.json`
records the exact source commit and signing status.

Native permission flows, media codecs, multi-display behavior and the complete
visual experience still need real-Mac acceptance. Only Apple Silicon is packaged.
Full native reference parity, automatic social posting, managed Teams, broader
professional workflows, native account/cloud sync and notarized release packaging
remain unfinished. See [`docs/native-suite-parity.md`](https://github.com/salmuflahi/rabta/blob/v0.2.0-beta.1/docs/native-suite-parity.md)
for individual feature status. No billing was added.
