# Free Framer marketplace assets, as the effect vocabulary

Everything below was listed free on framer.com/marketplace on 5 September 2026 (names and authors exact, so they can be searched). Claude Design cannot install Framer components; use each as the reference for how an effect should behave. If the final site is ever built in Framer, these are the drop-ins.

## Scroll and structure

- Lenis (darkroom.engineering): smooth scroll for the whole site.
- Scroll Zoom Reveal (Elephanta Agency): the capsule gathering in chapter 3, the mark arriving in chapter 11.
- Curtain Reveal Anim (Hey I'm Ozenua): page transitions and chapter cuts.
- Floating Pill Nav (Omer Mirza), Motion Minimal Navs (Matt), Modern Navbar (Kumar SK), Pill Dropdown Nav (Matt), Full Width Navbar (Val Casanova): the nav. Liquid Glass Navbar and Liquid Glass Footer (Matt) only in the Night studio direction.
- Line Menu - TOC (Till Janek): the film's chapter index and the Setup stepper.
- Feature Flipper (Amr Khaliili): the receipt chapter's four words.
- Logo Blur Carousel (Sanna Granqvist): the works-with row.
- Service Accordion (Pentaclay): FAQ.

## Type

- Text Video Mask (KIBERU YAHAYA): the Signal direction, footage punched through letters.
